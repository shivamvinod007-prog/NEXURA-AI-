Database & Authentication Architecture

Database Used: Browser LocalStorage / IndexedDB (Client-side persistent layer). Fully structured for seamless migration to PostgreSQL / Supabase.

Authentication Provider: Client-side cryptographic state manager with session tokens. Easily connectible to Supabase Auth or Firebase Auth.

Setup Remaining for Production:

  • Provide Supabase / Firebase project credentials in environment variables.
  • Enable Row Level Security (RLS) policies on user document and quiz tables.
  • Connect serverless vector embeddings endpoint (e.g. pgvector) for large-scale chunk similarity search.
